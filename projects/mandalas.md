# The Mandalas

Two related builds: interactive maps of the founder's whole system — every language, kernel, and agent placed as a node in one coherent geometry, so the architecture can be *seen* instead of listed.

## The SI Core Mandala

A single self-contained page rendering the system's intelligence core as a navigable mandala, shipped with its underlying data file so the geometry is inspectable, not just viewable. The build record includes a cross-examination of the piece against its predecessor — an honest accounting that lists true losses alongside gains, because a prettier successor that quietly drops capability is a regression wearing makeup.

## The AltaminaC Mandala

The larger map: 64 nodes — a core, a nine-piece court, 36 languages, 18 kernels — arranged on a braided geometry of nine lineage strands. The court's nine pieces carry the names of the founder's earlier builds, kept as lineage rather than discarded.

Working features of record:

- **Coherence, measured** — the layout is driven by a coherence-seeking pass over the node relationships, and the build reports its achieved coherence value rather than asserting harmony.
- **A phase-shifting core** — tapping the core cycles it through named phases with distinct color states.
- **Resident dwellings** — agents are residents of the mandala, not annotations on it, under a **Resident Traffic Protocol**: residents travel between nodes carrying invitations (query, translation, conflict, gap, relay, exploration, return); disagreement between residents is preserved as data, never flattened by a supervisor; translation loss is a first-class, recorded quantity. The invariant: **travel grants access, not native authority.**
- **An era ring** — the boundary marks which pieces stand alone and which arrived since the system unified.

Both mandalas are single-file, offline-capable builds — the pattern the house ships everywhere: no server, no account, no meter.
