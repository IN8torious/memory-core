# The Core Fun Loop — Hunt → Change → Witness → Escalate

*The design doctrine for built worlds — and, read honestly, a description of how the founder himself stays engaged with any system, games included.*

## The loop

**Explore → Spot something strange, useful, or dangerous → Commit to an action → the World reacts visibly → Gain knowledge, capability, or access → the World evolves around that gain → Push deeper.**

The core verb is **TRANSFORM**. The player changes the world and sees the change remain. The reward is not loot; it is visible authorship — restore power and watch a district wake up; redirect water and alter the terrain; repair a machine and open a new route.

## The scales

- **20 seconds:** see target → read its behavior → choose an approach → act → immediate feedback → reposition. Must feel good with progression disabled.
- **5 minutes:** enter a region → find its problem → experiment → cause a meaningful change → reveal a deeper opportunity. Leave thinking: *I changed that place, and now I want to see what my change unlocked.*
- **A session:** choose an expedition → alter the situation → extract a new capability → return to an evolved world → choose a harder expedition. Progression changes the next *decision*, not just the numbers.
- **The long loop:** the world remembers → new states become possible → systems collide → mastery deepens → the world demands deeper mastery.

## Reward hierarchy

In this order: **immediate feel → visible consequence → new understanding → new capability → persistent transformation → escalated possibility.**

Never let inventory or numbers replace visible world change.

## Anti-boredom laws

- Never repeat a solved problem unchanged.
- Never delay the interesting mechanic.
- Never generate variation that changes only appearance — if it changes decisions, it's gameplay; if it only decorates, it isn't.
- Failure should create information, not dead time: fail → learn why → keep what was discovered → return quickly.

## Final form

**LOOK → NOTICE → COMMIT → TRANSFORM → WITNESS → ADAPT → GO DEEPER**

The real fantasy is not saving the world. It is understanding a living world well enough to leave fingerprints on it.
