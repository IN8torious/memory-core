| [carpenter-law.md](carpenter-law.md) | An engineer doesn't wait for tools — he makes them, replaces them, and moves on. |
| [core-fun-loop.md](core-fun-loop.md) | The engagement loop for built worlds: Hunt → Change → Witness → Escalate. |
| [ancestry-and-local-time.md](ancestry-and-local-time.md) | The memory integrity laws: nothing derived may modify its ancestor; mass from evidence, never repetition; every memory keeps its own local time; replay detects drift. |
