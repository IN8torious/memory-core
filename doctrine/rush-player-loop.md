# The Rush-Player Loop

*The house work cycle. It began as one player's doctrine in hardcore search-and-destroy — spawn, read the field, push the objective, adapt, next round — recompiled as the operating cycle for agent work. Same mindset, different arena.*

**Centre law: IDEA → ACTION → EVIDENCE → EVOLUTION.**

## The six stages

1. **INTEL** — Read the objective, scan the environment, identify the key targets, load prior knowledge. *(Fast — under a minute of framing, not an afternoon of it.)*
2. **PLAN** — Choose the fastest viable route, mark the high-value actions, define the exit condition.
3. **EXECUTE** — Move fast. Parallel lanes, minimal idle, adapt to new information, don't overthink. First visible result early — minutes to an hour and a half, not days.
4. **VERIFY** — Grade against the target. Automated tests, divergence hunted, visual and data both validated. **No guessing.**
5. **ADAPT** — Works → scale it. Close → fix and retry. Fails → extract the useful parts, reassign, update the plan.
6. **RECYCLE** — Harvest assets, code, and ideas into the next run. Discard what's obsolete. A finished project isn't a trophy — it's material.

## Speed laws

- **Evidence on a cadence.** During active build work, something visible lands roughly every 90 minutes — an artifact, a measurement, a convicted failure, a reproducible blocker. "Still working" is not evidence.
- **First divergence wins.** Don't inspect the whole failure when the first divergence can be found. Earliest frame, earliest state, earliest contract that differs — convict that, correct one class, replay everything prior.
- **No self-grading.** The builder never controls the fixtures, the references, or the final verdict on its own work.
- **Kill stagnant branches.** Cycles of meetings, documents, and plans with no visible output get killed. Useful parts are cannibalized into the next experiment — no dead ends.
- **Report delta, never effort.** Before → after counts. Never hours worked.

## Status vocabulary

Only these words, and only when the evidence supports them:

**PROPOSED · BUILT · RUN · MEASURED · VERIFIED · PROMOTED · REFUSED · BLOCKED · RECYCLED**

A refusal is a valid result. A test that cannot fail the artifact is decoration.

## Mindset

Speed over perfection, action over analysis, information through motion. Small wins compound. No attachment to outcomes. Everything is a resource.
