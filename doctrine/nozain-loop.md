# The Nozain Loop

*The spine every dispatch and delivery runs on. Named for Nozain, the unified system the loop was drawn from: two peer seats — cognition asking "what should I do?", consequence asking "here is what this costs" — arbitrated by the world itself: "here is what actually happened."*

## The spine

```
PROPOSAL → PREDICTION → ACTION → WORLD RESULT → EVALUATION → ADAPTATION → RECEIPT ↺
```

1. **PROPOSAL** — The brief, stated in the founder's terms, from his materials.
2. **PREDICTION** — A written consequence pass, made *before* the action and preserved in the brief: what it costs, what could fail, what is unverified. Where the prediction disagrees with the proposal, the disagreement is kept on the record — never flattened to make the plan look clean.
3. **ACTION** — The work is done.
4. **WORLD RESULT** — What actually happened, taken from evidence — never from the plan.
5. **EVALUATION** — The result graded against the prediction: **matched · missed · still unknown.**
6. **ADAPTATION** — The lesson carried into the next brief, so the system prices the next action better.
7. **RECEIPT** — The loop closes only when a receipt is written to the record.

## Laws of the loop

- **A delivery without a closed loop is a claim, not a result.**
- **Receipts are append-only.** Corrections supersede by reference; history is never edited to look smarter than it was.
- **Prediction is priced before action.** Surprises are data about the predictor, not embarrassments to hide.
- **The clarification gate rides the loop:** low confidence → ask, don't guess.
- **Scope:** the loop binds work — dispatches and deliveries. Conversation doesn't carry the ceremony.
